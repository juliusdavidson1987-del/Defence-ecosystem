# Contributing to The Defence Ecosystem

Thank you for helping keep this map accurate. Corrections, new organisations,
and fixes are all welcome — the tool gets better because people who know a
corner of the ecosystem take the time to improve it.

## Licensing of contributions (please read)

By submitting a contribution — whether through the in-tool suggestion form, a
pull request, an issue, or any other channel — you agree that your contribution
is provided under the same licences that cover this project:

- **Data / content contributions** (organisation entries, descriptions,
  corrections, categorisations) are licensed under the
  **Creative Commons Attribution 4.0 International Licence (CC BY 4.0)**.
- **Code contributions** are licensed under the **MIT Licence**.

In other words, *inbound = outbound*: you keep authorship of what you submit,
but you license it to the project on the same terms the project licenses to
everyone else. This keeps the dataset cleanly relicensable and free for all to
reuse. Please only submit material you have the right to contribute, and do not
paste text lifted verbatim from an organisation's website or other copyrighted
source — describe it in your own words.

## What makes a good contribution

- **Accuracy over completeness.** A verified, hedged entry beats an impressive
  but unconfirmed one. Don't inflate a small nation's capability.
- **Own words.** Write descriptions yourself; don't copy site copy.
- **Verified links only.** Only include a URL if you've confirmed it loads and
  is the correct official page.
- **Cite where it helps.** If a fact is drawn from UK public sector information,
  note it so the Open Government Licence attribution can be applied.

## How to contribute

- **Quickest:** use the "Suggest a correction" button inside the tool. It opens
  a short form and reaches the maintainer directly.
- **Larger changes:** open an issue or pull request describing what you'd change
  and why, with sources.
